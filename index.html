Features

三段主线，加上一整套工程增强

核心只有三步，但要在无人值守下稳定跑几万次，需要解决的问题远不止三步。 下面 15 项能力覆盖从采集到归档的完整闭环，并可整套容器化部署。

01 下载视频 采集侧 · D:\视频\自媒体视频库

账号增量采集

批量下载 N 个抖音账号的全部作品，原画质。工具自带的 DB + 文件双重判断让增量天然成立，无需额外维护状态。

_pipeline.py · 两阶段试水 + 自动改名

合集采集

按 collection 链接采集指定合集，长播客单文件可达 1GB+。跑完自动恢复配置，不会污染次日任务。

_dl_mix.py · 临时切 run_command 后还原

新账号快速入库

只拉 30 列元数据清单与封面，不下载视频。有了清单，后续才能按需「只下音频」。

_acct_fetch.py · CSV 按作品ID 去重可反复跑

磁盘闸门

空间不足时先回收残留 mp4 再复测；仍不足则整轮跳过并退出码 2，绝不让磁盘写满导致数据不一致。

ensure_space() · MIN_FREE_GB 默认 20
02 转换音频 抽流 / 直下

视频转音频

优先无损抽流（-c:a copy，秒级），失败再重编码 64k 单声道兜底。先写临时文件再原子替换，不留半成品。

_to_audio.py · 实测体积降至约 1/8

音频直下

绕过视频，直接从接口的纯音频档拉音轨，省掉「下视频→抽音轨→删视频」整步。含限流退避与最小 mp4 兜底。

_audio_direct.py · 4h 播客 668MB → 81.8MB
03 文案转写 知识侧 · D:\视频\媒体知识库

ASR 转写 + LLM 摘要

本地 ASR 服务转出逐字稿，再由 LLM 生成 4 个关键词与结构化内容总结。总结只依据逐字稿真实内容，严禁按标题脑补。

asr_batch.py · stage1 转写 / stage2 渲染

长视频切段拼接

时长 ≥ 20 分钟自动切片，每段独立落盘与登记。中途崩溃只重跑未完成的段，已完成段永久复用。

_seg_for() · 段数 ceil(dur/900)

实时看板

看板自算进度（服务端状态码形同没有），显示当前条目、真实耗时与引擎逐词流式输出。

webui.py · :8770 局域网可访问
04 工程增强 让上面三段能长期稳定跑

命名规范化

统一为 日期_昵称_作品ID.ext，键唯一且稳定。依据 CSV 映射，多 ID 歧义与无映射一律跳过不猜。

_rename.py · 双前缀匹配合集特例

封面三级兜底补齐

CSV 静态封面 → CSV 动态封面 → Detail 接口 images / video.cover。图集只有序号图时自动补一份标准名。

_cover_audit_fix.py · --check 只报告

数据双向自愈

一个方向删记录放行重下，另一个方向补记录防止重下。两者相容且必须成对使用，终检要求同时归零。

_repair.py + _seed_done.py · 双 0 终检

云端增量归档

经本地 alist 把新增音轨与封面增量推到夸克网盘。SQLite 状态库记录已传文件，中断续传、重复跑幂等。

_upload_alist.py · --jobs 3 ≈ 67 文件/分

Architecture

两库分离，一切以 CSV 为准

Quick Start

一轮完整链路

环境：Windows 10/11 · Python 3.10+ · ffmpeg。采集侧需要一个抖音网页版 Cookie。

采集侧 · D:\视频\自媒体视频库 复制 
# 进入采集侧工作目录
cd /d D:\视频\自媒体视频库

# ① 先修数据：把「有记录但文件缺失」的作品放行重下
python _tools\TikTokDownloader\_repair.py --apply

# ② 账号增量采集（含磁盘闸门与自动改名）
python _tools\TikTokDownloader\_pipeline.py

# ③ 合集增量采集
python _dl_mix.py

# ④ mp4 → m4a 并删除源视频回收磁盘
python _to_audio.py --delete

# ⑤ 已落盘作品回填下载库，防止次日重复下载
python _seed_done.py --apply

# ⑥ 封面审计 + 三级兜底补齐
python _cover_audit_fix.py
知识侧 · D:\视频\媒体知识库 复制 
# 数据源固定指向采集侧
cd /d D:\视频\媒体知识库
set WB_SOURCE=lib

# 转写（长视频自动切片；只转写、不渲染 md）
python asr_batch.py stage1

# 渲染 md（关键词 + LLM 总结 + 复制封面），另开一个进程
python _stage2_daemon.py
